Projects

What I have built

Corporate AI Agent (Claude + RAG)

An assistant built on Claude with 8 tools that query classes, students, CRM deals, KPIs, documents and Canva, plus web search. Voice input (Whisper), per-user preferences and LLM usage and cost governance by model and by person. Document answers use RAG over a company knowledge base, with personal data masked before indexing (LGPD) and permission-aware retrieval. Full-text search in Portuguese and English today, with the vector layer prepared as the next phase.

  • Claude (Anthropic API)
  • Tool use
  • Whisper
  • PostgreSQL
  • Next.js
  • Supabase

API for an AI sales agent on WhatsApp

The training system's public API is consumed by an AI agent that talks to leads on WhatsApp, so the contract was written for an LLM reader: list order is a business rule (the agent offers the first item), an invalid preference filter never leaves the agent without options, there are no ambiguous nulls, no contradictory signals, and anything in the response may be said to the customer.

  • Node.js
  • Express
  • TypeScript

Training management system modules

Certificate tracking fed by confirmed classes, one-click pre-course emails per class, a weekly authorized-participants list sent to the building reception every Monday, hourly Pipedrive sync for B2B companies, e-learning certificates generated and sent for e-signature in one click, assessments with auto-proctoring replacing an Excel control, onboard training cycles and a role and permission matrix.

  • Express
  • React
  • Supabase

Digital certificates

PDF certificates from templates (11 for e-learning) with a QR code that opens a public validation page, e-signature through D4Sign and hourly status sync. A task that took 3 to 5 hours a week became a few clicks.

  • Next.js
  • Supabase
  • D4Sign

Corporate portal

One login for the company's internal tools: 85 screens with CRM, marketing, document management with SharePoint import, OKRs, boards and meetings, commercial proposals with an AI-generated landing page, an executive dashboard fed by Pipedrive and the AI agent. Role-based access per module and action, audit trail and 2FA.

  • Next.js
  • Supabase
  • Vercel

Inventory and purchasing

Stock in and out with a barcode scanner, purchase orders, supplier evaluation in PDF, reports, low-stock alerts and automatic email summaries (daily, weekly and monthly).

  • Next.js
  • Supabase
  • shadcn/ui

MARVIS fire & gas simulator

A training that ran as a macro-enabled PowerPoint, rebuilt as a faithful offline desktop app that runs on a kiosk or from a USB drive, with no internet or database. Shipped as an installer and a portable version.

  • Electron

Satisfaction dashboard

Student survey answers feed a Looker Studio dashboard automatically.

  • Looker Studio

Second brain for AI agents

A git repository of Markdown notes, synced by Claude Code hooks at the start and end of each session, that keeps rules, skills, decisions and lessons the same on any computer, with a knowledge graph in Obsidian.

  • Git
  • Claude Code hooks
  • Markdown
  • Obsidian

VMT Office: AI agent observability

A pixel-art virtual office that shows, live, what each Claude Code session on the team is doing, one desk per session. Hooks capture events, a server receives them and the browser draws the office in real time.

  • Node.js with no dependencies
  • Server-Sent Events
  • Docker

Learning platform, with a development agency

Trilingual website, checkout with Pagar.me and Stripe, LMS and admin. My part: requirements and prioritization with the agency, feature work, automated tests and end-to-end validation, with 85+ merged deliveries and 75+ tasks in six weeks.

These are internal systems that handle real student and client data, so there are no screenshots here.
